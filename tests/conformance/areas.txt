# The map from an upstream spec file to a row of docs/support-matrix.md (#759), read by matrix.py.
# One line: <suite> <glob> <section> | <feature>
#   suite    wp, wc, wc-api or gb (as runner.py names them)
#   glob     the spec file as the Playwright report names it, the same form as exclude/<suite>.txt;
#            * matches across directories
#   section  WordPress or WooCommerce (a heading of the matrix)
#   feature  the row's first cell. A feature not yet in the matrix is added as a new row by --apply.
# The FIRST matching line wins, so a specific file goes above its directory. A spec no line maps is
# listed as unmapped in matrix.py's report, so a gap in this map is visible, never silent.
# Built from the step-1 browser inventory (#759 issuecomment, joan-sb1114h, 2026-11-16).
