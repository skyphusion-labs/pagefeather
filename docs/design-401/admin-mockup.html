Import

Move content from another WordPress site

  1. On your old site, go to Tools > Export. Choose All content. Select Download Export File.
  2. Log in to your new site. Go to Tools > Import > WordPress. Select Run Importer.
  3. Upload the file. Choose Download and import file attachments. Keep your old site online until the import ends, so the images can be copied.
